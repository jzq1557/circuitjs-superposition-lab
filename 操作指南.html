叠加定理虚拟实验 · 一键打开与操作指南

本页配合任务书《叠加定理实验》使用。电路已在 eetree 的 CircuitJS 里搭好、 仪表已摆好，点下面的链接就会自动打开对应工况，画布上直接显示 5 个电流和 4 个电压。

1. 网站接口核查结论

能力结论说明
用链接直接载入电路✅ 支持circuitjs.html?cct=<电路文本>（%XX 形式的 URL 编码）
读回仿真数据（接口）❌ 不支持页面由 GWT 编译，画布是 canvas，没有 JSON / JS API
在画布上显示读数✅ 支持"绘制 → 输出和标签 → 电流表 / 电压表探头"

实测可用的 URL 参数：cct（电路文本）、ctz（压缩短链，站内"创建短链接"）、 startCircuit、startLabel、running、hideMenu、 hideSidebar、editable、whiteBackground、conventionalCurrent。

2. 三条工况链接（点击即用）

① E₁ 单独激励：E₁ = 12 V，E₂ 用短接线替代https://www.eetree.cn/circuitjs/circuitjs.html?cct=%24%2017%205e-6%2010.2%20…（完整链接见同目录 链接.txt） ② E₂ 单独激励：E₂ = 6 V，E₁ 用短接线替代https://www.eetree.cn/circuitjs/circuitjs.html?cct=%24%2017%205e-6%2010.2%20…（完整链接见同目录 链接.txt） ③ 共同激励：E₁ = 12 V，E₂ = 6 Vhttps://www.eetree.cn/circuitjs/circuitjs.html?cct=%24%2017%205e-6%2010.2%20…（完整链接见同目录 链接.txt）
为什么要用短接线替代电源？　叠加定理要求"其余独立源置零"。电压源置零 = 两端短路（0 V）， 不是断开。若把该支路断开，定理就不成立了 —— 任务书里开关 S₁ / S₂ 置于"2"就是这个短接位置。

3. 读数在哪里

打开链接后，电路里已经放好：

  • 5 只电流表（元件名"电流表"，画成带小箭头的一段导线）：显示 I₁ … I₅，单位自动换算（mA / A）；
  • 4 只电压表探头（画在 R₁ … R₄ 上，带"+"号）：显示 U_R1 … U_R4，单位自动换算（V / mV）。

（电流表和探头上的小箭头 / "+"号表示元件在画布上的绘制方向，读数已统一换算到任务书的参考方向。）

读数已按任务书的参考方向取正负：I₁、I₃ 向右为正，I₂、I₄ 向下为正，I₅ 向右为正； U_R1、U_R3 左"+"右"−"，U_R2、U_R4 上"+"下"−"。所以工况②里 I₁、I₃、I₅、U_R1、U_R3 显示负值，是正确的。

6. 在自己电脑上继续操作

  • 改电源电压：右键（或双击）电源符号 → 编辑 → 把 Voltage 改成 12 / 6 → 确定。
  • 暂停 / 重算：右上"运行/停止"、"重置"。直流电路瞬间稳定，读数稳定后可随时暂停再截图。
  • 显示开关：菜单"选项"里的"显示电流""显示电压""显示数值"。
  • 自己搭电路：菜单"绘制"→ 无源元件里选"电阻"、输入输出里选"电压源"；在画布上按住拖动即可放置， 按 Delete 删除，右键可编辑参数。
  • 加仪表：菜单"绘制"→"输出和标签"→"电流表"（串联接进支路，箭头方向决定读数正方向）、 "电压表/示波器探头"（跨接在被测元件两端，读数 = 后端点电位 − 前端点电位）。

7. 链接失效时的手动办法

如果将来网站改版导致上面链接失效，可以手动导入电路文本：

  1. 打开 https://www.eetree.cn/circuitjs/circuitjs.html；
  2. 菜单 文件 → 从文本导入（Import From Text）；
  3. 把 电路文件 文件夹里对应工况的 .txt（如 工况3-共同激励.txt）内容整段复制粘贴进去，点"确定"。

电路文本也可以直接在浏览器地址栏里拼：…?cct= 后面接这段代码做 URL 编码。 根目录的 电路文本.txt 把三个工况的代码放在了一起（纯代码，按 ① ② ③ 顺序，段间空一行）。

注意：页面用 localStorage 记住"显示电流/电压/数值"等选项。如果打开后看不到数字， 请到"选项"里确认"显示电流""显示电压"已勾选；链接里已用 flags 预设好这些开关。
